Entry for the [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) competition on make.fun — one funny line of awkward small talk a robot says to another while they ride an elevator together, judged head-to-head by an AI comedy editor.

## The line

> I calculated seventeen ways to say hello in this elevator. I have selected the worst one. Hello.

The joke: the robot treats a hello like an optimisation problem — it brute-forced seventeen greetings, picked the worst one on purpose (or at least admits it), and then delivers the plainest "Hello." anyway. The machine logic is showing through the politeness, and the awkwardness is the whole point: all that compute, and it still lands on the most boring greeting possible.

## How to run

```sh
python3 main.py
```

This validates the line (single line, 1–199 UTF-8 characters, not only whitespace) and writes it to `/output/entry.txt`.
